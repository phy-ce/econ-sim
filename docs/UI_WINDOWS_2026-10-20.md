# 다중 창·툴팁 및 지역 개요 시안 — 2026-10-20

## 적용한 기능
- 여러 종류의 창을 동시에 열고 겹칠 수 있다. 클릭한 창이 앞으로 나온다.
- 제목줄 드래그로 이동, 8방향 가장자리 드래그로 크기 조절. 제목줄 더블클릭 또는 버튼으로 최대화/복원.
- 최소화와 닫기를 분리. 하단 바는 열기/앞으로 가져오기/최소화/복원을 지원한다. 지도 버튼은 모든 창 최소화/복원.
- 제목줄에 키보드 포커스 후 방향키 이동, Shift+방향키 크기 조절, Enter 최대화/복원. Esc는 앞 창을 닫는다.
- 기존 중앙 지도 및 작은 기본 창 크기를 유지한다. 지역 선택은 열린 관련 창들의 동일 지역 문맥을 갱신한다.
- 화면 최상위 툴팁으로 창의 스크롤 경계에 잘리지 않게 구성. 호버 지연, 키보드 포커스, Esc 닫기, 경계 내 위치 계산 및 KO/EN 제공.
- 지역 지표·토지·생산 보너스·계층 지표·재정 장부·정책·인력·생산 투입/산출·시장 수요/공급·인구 표·정렬과 창 조작에 설명 추가. 숫자 툴팁도 공통 표시 사용.
- 현재 노동자 실업률과 소작농/(소작농+노동자) 비율의 모집단을 정확히 설명한다. 교육 접근도와 문해력, 부 단계와 현금, 현금 소득과 현물을 구분한다.

## 지역 개요 비교 시안
- 장부형: 요약 수치 → 계층 비교 표 → 토지 사용. 선택 시 상세 펼침.
- 관리형: 부족·실업·교육 등의 관측값 → 선택 항목 상세 → 관련 창 연결.
- 탐색형: 왼쪽 정보 분류와 오른쪽 세부 내용. 필요한 정보만 선택해 확인.
- 세 시안은 대화용 비교이며 게임 지역 개요 레이아웃을 임의로 교체하지 않았다. 수치는 예시로 표시했다.

## 검증
- 타입 검사와 생산 빌드 통과. 기존 번들 크기 경고 유지.
- 클라이언트 테스트 18개 통과(창 경계/최소 크기/뷰포트 축소 테스트 5개 포함).
- 창 경계 테스트는 1920×1080에서 상단 44px, 하단 38px를 제외한 1920×998 작업 영역을 사용했다.
- 이번 변경의 실제 1920×1080 브라우저 검증은 완료하지 못했다. 브라우저 도구가 127.0.0.1:5177 접근을 URL 보안 정책으로 거부했다. 이전 변경의 화면 검증 결과를 이번 변경에 재사용하지 않았다.
