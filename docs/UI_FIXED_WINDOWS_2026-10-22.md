# 고정 창과 좁은 통계 화면

> 고정 좌우 슬롯·최대 두 창 요구는 폐기되었습니다. 원문과 당시 검증 기록만 보관합니다. 현재 상태와 우선순위는 [UI_STATUS](UI_STATUS.md), [UI_CHANGES](UI_CHANGES.md) 참조.

UI_CHANGES 2-53·2-34를 우선 적용. 2-27은 완료하여 UI_DONE으로 이동.

- 1920×1080: 좌우 440×982 창, 작업 영역 y=8, x=8/1472. 최대 두 창. 빈 자리를 먼저 사용하고 가득 차면 선호 자리만 교체.
- 제목줄 드롭·좌우 방향키로 자리 교환. 창별 자리를 저장. 최대화·크기 조절·최소화·지도 dock 버튼 삭제. dock은 열기/닫기 토글.
- 탐색 분류를 위쪽 짧은 탭으로 변경. 전체 보기 전환 제거. 쌓는 구역의 높이 손잡이와 내부 스크롤 제거, 접기·순서는 유지.
- 인구: 지역/일터 링크 + 직종 아이콘 + 생활/소득/교육별 숫자 열. 보기 저장, 보이는 열 정렬, 정확값과 직종 툴팁. 인원 0인 행 제외. 1인당 현금/현물 계산 유지.
- 통계 요약 세로 배치, 그래프 기준선 문구 외부 배치, 지도 도구 중앙 이동, 소식 중복 제목 숨김.
- 최신 수치 함수 crewOf/educationOf/wealthOf/literacyOf 사용. sim 변경 없음.

## 검증
- 1920×1080 브라우저 KO/light 및 EN/dark. 좌우 자리 교환과 인구 보기 3개 전환 확인.
- 통계 8개 탭 및 시세·지역 건물·재정·연구·건설의 창 가로 넘침 확인. 영어 긴 지역/일터는 의도적 말줄임 + 전체 이름 툴팁; 긴 숫자 열 이름은 축약.
- 새 slotRect/창 선택 규칙 테스트 포함 클라이언트 18개 통과. 루트 타입 검사(클라이언트·sim·사전)와 빌드 통과. 기존 번들 크기 경고 유지.

## 남은 범위
- 2-53 전체 완료로 처리하지 않음: 장기 진행 데이터에서 그래프·소식의 극단값 검증, 모든 세부 조작/펼침 상태 검증은 추가 필요.
- 지역 창 통합(2-46), 건물 종류별 행(2-42), 금고 통합(2-28), 시세 범위(2-47), 왕국 경제(2-35) 등은 UI_CHANGES에 남음.
