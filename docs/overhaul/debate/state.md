# 토론 기록: 국가: 재정·세금·예산·법·정치

이 기록의 결과물은 `docs/overhaul/05_STATE.md` 다.
사용자 지시 (고정): "경제 샌드박스"라는 틀은 유지한다. 시장·계층·돈의 흐름이 주인공이고, 플레이어가 스스로 목표를 세워 경제를 읽고 고친다. 정치·경쟁·이벤트·목표는 이 틀 위에 얹는 층이며 틀을 대신하지 않는다. 틀을 버리자는 비평은 기각한다.
근거 자료: `_brief/01~04`, `01_VISION.md`, `02_CORE_LOOP.md`. 시뮬레이션은 돌리지 않았다. 옛 보고서 숫자는 조건을 붙여 "그 조건에서 본 것"으로만 인용한다.

## 라운드 1

대상: `05_STATE.md`. 조건: main `5fdefe7`, 새 시뮬레이션 없음. 틀(경제 샌드박스)을 버리자는 비평은 없었다. 판정관이 코드를 읽어 확인한 줄 번호는 지적마다 적었다.

### 지시 (반영함)
