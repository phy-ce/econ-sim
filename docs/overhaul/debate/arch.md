# 토론 기록: 기술 구조와 이행: sim 구조·데이터·테스트·이행 순서

결과물은 `docs/overhaul/10_ARCHITECTURE.md` 다.
사용자 지시 (고정): "경제 샌드박스"라는 틀은 유지한다. 시장·계층·돈의 흐름이 주인공이고, 플레이어가 스스로 목표를 세워 경제를 읽고 고친다. 정치·경쟁·이벤트·목표는 이 틀 위에 얹는 층이다. 틀을 버리자는 비평은 기각한다. 이번 라운드에서 틀을 버리자는 지적은 없었다.

## 라운드 1

### 비평가별 점수와 요약
- **아키텍트 6점**: 전제(규칙 불변, 샌드박스 틀 유지, 측정 후 확정, 모르는 것을 모른다고 적음)와 관측 전용 기록 분리는 탄탄하다. 그러나 몫의 장부 닫힘과 되감기·분기 실험이 구조적 보증 없이 관측과 사람의 규율에 기댄다. 저장은 갈래 시간선을 섞고, rulesRev 는 수동이며, samecheck 는 드문 경로를 못 보고, 계층 규칙은 자기모순이고, 03~09 와 접점이 어긋나며, 성능은 Node 평균만 봤다.
- **경제학자 6점**: 샌드박스 틀을 지켰다. 다만 약속이 구조가 아니라 검사에 기댄다. 장부 닫힘을 가장 늦게 안다, 잡음 대역의 통계 정의가 거짓 '효과'를 자주 낸다, 얼린 RULES 가 CLAUDE.md 의 비교 선택 절차와 부딪힌다, 규칙 판 식별에 건물·상품·기술 표가 빠진다, 시간 간격 저장이 "처방 앞으로 돌아가기"를 보장하지 않는다.

- **E1 (major)** 장부 닫힘이 구조가 아니라 사후 시험이다 (A 단계에서야 앎). 허용오차 식이 큰 누락을 숨긴다 → **부분 수용** (AR1 과 합침). 이주·사망·상속은 처음부터 `이동` 선으로 둔다. 허용오차 식이 큰 누락을 숨긴다는 주장은 과장이다 (누락은 흐름 크기 차수라 ε·Σ|흐름| 을 크게 넘는다). 그래도 4.4 식에는 괄호가 없어 Σ|낸| 전체를 허용하는 결함이 있어 `ε · (Σ|받은| + Σ|낸| + |저축|)` 로 고친다. `transfer()` 강제는 탐침 뒤로 미룬다.
