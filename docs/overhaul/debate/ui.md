사용자 지시 (고정): "경제 샌드박스"라는 틀은 유지한다. 시장·계층·돈의 흐름이 주인공이고, 플레이어가 스스로 목표를 세워 경제를 읽고 고친다. 정치·경쟁·이벤트·목표는 이 틀 위에 얹는 층이며 틀을 대신하지 않는다. 틀을 버리자는 비평은 기각한다.
