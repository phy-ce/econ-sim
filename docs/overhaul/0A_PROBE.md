## 결론 (이 조건에서 본 것)
1. 대조: (1)의 간격이 해마다 (2)보다 작지 않았다. 시드 평균으로 칸별 14/25 칸만 (1) < (2) (시드 1: 7/25, 시드 2: 17/25).
   해별로 시드 평균 (1)<(2) 인 지표 수: 1년 0/5, 2년 3/5, 3년 5/5, 4년 3/5, 5년 3/5. 모든 해에서 작았던 지표 없음 (1년차는 5개 모두 (1)이 컸다).
   (1)의 간격을 0a salt 28쌍 간격 분포에 넣으면 평균 분위 0.52 (50칸, 같은 분포면 0.5): 0a 이전에는 공유 난수 하나를 더 쓰는 것만으로 AI 난수 소금을 바꾼 것과 같은 크기의 분기가 났다.
   → 3.8 "결과별 행동"의 "그 밖" 경우다. 정당화("0a 는 처방과 무관한 분기를 줄인다")를 그대로 둔다. D10-S1(Q3) 재질문 조건에 해당하지 않는다.
2. null 효과 판정 오경보율 (가족 단위): 고정 20쌍 × 시드 2 = 40번 비교 중 18번(45%)에서 25개 판정 중 하나 이상이 '효과'. 판정 단위로는 30/1000 = 3.0% (교환 가능할 때 이론 2/70 = 2.86%). 35개 분할 전부로는 32/70 = 46%, 50/1750 = 2.86%.
   해·지표가 독립이면 1−(1−2/70)^25 = 52% 이므로 상관 때문에 조금 낮아진 정도다. 5지표 × 5년 '효과' 라벨을 그대로 쓰면 처방이 없어도 비교 둘 중 하나 꼴로 무언가 '효과'가 뜬다.
3. 거짓 단서율: (가) 수준 값 7/16 = 44% 실행에서 단서 하나 이상 (지표 단위 10/80 = 12.5%; 국고 5, 노동자 3, 소작농 2, 곡물 0, 총생산 0).

   참고: 대역을 나머지 7개 중 4개 35가지 전부로 바꿔 평균하면 (가) 39%, (나) 55%.
4. 제안 (0b 이후용, 이번 병합 판정과는 별개): 효과 판정을 지표 하나·해 하나로 미리 정해 보거나(그러면 판정 단위 2.9%·한 방향 1.4%), 25개 판정 보고에 위 오경보율 45%를 같이 적는다. 단서 배지는 거짓 단서율이 44~69% 라 지금 정의(연수 3, K=4)로는 처방 효과의 근거로 약하다: K 를 늘리거나(K=8 이면 실행 하나가 밖에 놓일 확률 2/9 = 22%) 연수를 늘리는 비교가 필요하다 (근거 없음, 이번에 재지 않음).
