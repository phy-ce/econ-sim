## 5. 영향력과 투표법

**한 줄**: 집단의 정치 힘 = Σ pop (투표법 가중치 × 인구 × 부 단계 × 그 집단 몫). 영향력 = 정치 힘 ÷ 모든 집단의 합.

### 5.1 "부" 의 정의: 인구 × 부 단계 (`igWealth`)
후보 둘을 main 93bc0b0 코드, 시드 1 로 읽었다 (scratch 탐침, 효과 없음):

| 직종 | 시작: 인구 × 부 단계 (백만) | 시작: 저축 + 금융가 지분 가치 (백만) | 10년차: 인구 × 부 단계 | 10년차: 저축 + 지분 가치 |
|---|---|---|---|---|
| 소작농 | 4.49 | 55.9 | 1.60 | 17.9 |
| 노동자 | 0.23 | 3.1 | 1.36 | 82.0 |
| 농부 | 0.07 | 1.0 | 2.86 | 226.5 |
| 기술자 | 0.02 | 0.3 | 0.71 | 88.4 |
| 전문가 | - | - | 0.06 | 34.4 |
| 하급 귀족 | 0.08 | 46.6 | 0.77 | 215.1 |
| 상급 귀족 | 0.01 | 13.3 | 0.16 | 140.9 |

- 1인당 (10년차): 상급 귀족 부 단계 19.3 대 소작농 1.1 (약 18배). 저축 + 지분 가치는 16,568 대 12.6 (약 1,300배).
- **고른 것: 인구 × 부 단계.** 이유: (1) 빅토리아3 Pops 문서 "political strength based primarily on its wealth level". (2) 모든 pop 에 늘 있다 (저택 자리에 앉은 귀족의 몫은 main 에서 pop 의 자산이 아니라서, 저축 + 지분으로 재면 귀족이 빠진다). (3) 사람 수가 들어 있어 투표법이 뜻을 가진다: 저축 + 지분으로 재면 보통 선거도 부자 정치가 되어 투표법을 넓혀도 영향력이 거의 안 바뀐다. (4) 부 단계는 날마다 천천히 움직여 세금·배당 날에 튀지 않는다.
- 약점: 과두정에서 "수백~수천 배" 인 빅토리아3 보다 1인당 차가 작다 (약 18배). 시작 날에는 모든 pop 의 부 단계가 1.0 이라 영향력이 투표권 있는 사람 수의 몫이 된다 (1년 안에 풀린다).

### 5.2 투표법 (단계 0 에서는 법이 아닌 읽기 값, `VOTING_LAWS`·`VOTE_WEIGHT`)

| 투표법 | 투표권 (가중치 1) | 가중치 0 | 빅토리아3 대응 (정치 힘) |
|---|---|---|---|
| 귀족정 `nobles` (지금, 모든 왕국) | 상급 귀족, 하급 귀족, 자본가 | 소작농, 노동자, 농부, 기술자, 전문가 | 전제 (귀족·장교 +50%), 과두정 (+ 자본가 +25%) |
| 재산 투표 `property` | 위 + 기술자, 전문가 (중층 이상) | 소작농, 노동자, 농부 (하층) | 재산 투표 (표당 +50, 부 문턱 20), 인구 조사 선거 (문턱 10, × 문해력) |
| 보통 선거 `universal` | 모두 | 없음 | 보통 선거 (표당 +50, 모두) |

- 빅토리아3 는 모든 pop 이 부에서 정치 힘을 받고 법이 배율이나 표를 더한다 (더하기). 사용자 식은 곱하기 하나라서 "투표권 없음 = 0" 으로 줄였다. 그래야 투표법을 넓힐 때 영향력이 옮겨 간다 (곱하기에서 모두에게 같은 가중치를 주면 아무것도 안 바뀐다).
- 지주 투표(Landed Voting)는 따로 두지 않았다: 우리 직종에서 "땅·자본 가진 사람" 은 귀족과 전문가 몇천 명이라 귀족정과 거의 같다. 상급 귀족 ×1.5 (전제 +50%) 도 두지 않았다 (가중치 0/1 로 규칙 한 줄).
- 기본 귀족정: 지금 왕실 하나에 투자법이 귀족만에서 시작하는 세계와 맞춘 것이다 (근거 없음, 사용자 확인 12장).

## 8. 법 저항 (단계 2, 사용자 확인 대기)

**한 줄 (제안 해석)**: **법을 바꾸려면, 새 법에 반대하는 힘센 이익집단(영향력 20% 이상)이 모두 만족(승인 +5 이상)해야 한다. 아니면 바뀔 확률 0% 다.**

지금 법 바꾸기 (2장) 에 끼우는 자리:
- "반대" = 새 법에 대한 입장이 지금 법보다 낮다 (빅토리아3: "endorse changes that move laws towards their preference and oppose changes that do the opposite").
- 시작할 때 본다 (금융가 비율 조건과 함께, 안 맞으면 시작 못 함) 그리고 180일 끝에 다시 본다 (SD11 만기 재검사와 같은 자리: 안 맞으면 실패, `lawFail`·`lawFailed` 소식에 막은 집단 이름).
- 복지법·투표법에도 같은 조건이 붙는다 (지금 복지법은 조건이 없다: 플레이어가 보는 규칙이 바뀐다).
- 판정에 쓰는 승인은 화면에 보이는 승인 그대로다 (바뀌는 중인 법의 충격은 바뀐 뒤에 넣으므로 판정을 스스로 떨어뜨리지 않는다).
- 읽기용 판정은 이미 있다: `igLawCheck(w, kingdomId, kind, to)` → `{ ok, blockers }`. 단계 0 에서는 아무것도 막지 않는다.

단계 0 관찰 (main 93bc0b0 코드, 20년 × 시드 1·2, 귀족정, AI 가 실제로 바꾼 법 중 이 규칙이면 시작이나 끝에서 막혔을 것, `cli/igdiag.ts`):

| 바꾼 법 | 시드 1 (막힘/횟수) | 시드 2 |

| 투자법 귀족만 → 전문가까지 | 0 / 3 | 0 / 3 |
| 투자법 전문가까지 → 기술자까지 | 3 / 3 (지주) | 3 / 3 |
| 투자법 기술자까지 → 노동자·농부까지 | 3 / 3 (소시민) | 3 / 3 |
| 세법 토지세 → 인두세 | 1 / 3 (지주) | 1 / 3 |
| 세법 인두세 → 토지세 | 3 / 3 (소시민) | 3 / 3 |
| 복지 없음 → 구빈법 | 3 / 3 (지주) | 3 / 3 |

- 이 조건에서 AI 가 바꾼 법의 약 70% 가 막혔을 것이다. 시작 법에서 지주의 입장 합이 정확히 +5 (만족 문턱) 라서 지주가 반대하는 첫 바꾸기는 통과하고, 그 뒤 입장 합이 내려가 (예: 투자법 한 칸 → +4, 충격 −5) 생활수준 항이 받쳐 주지 않으면 지주가 막는다.
- 빅토리아3 와 다른 점: 빅토리아3 는 반대 집단의 영향력과 기분으로 "정체" 확률을 올릴 뿐 0% 로 막지 않는다 (1장 법 제정). 사용자 표현 "만족못하면 0%" 를 문턱 하나로 읽었다. 다른 해석 (B): 바뀔 확률 = 1 − Σ 반대 힘센 집단 영향력 × (만족 0, 중립 0.5, 불만 1, 성남 1.5) 를 180일 끝에 한 번 굴린다 (빅토리아3 정체 식을 한 번으로 줄인 것). (A) 는 플레이어가 미리 알 수 있고 (B) 는 운이 든다.

## 9. AI 왕국의 법 고르기 (단계 2~3, AI 판단은 복잡해도 된다)

1. 시작 전에 `igLawCheck` 를 본다. 막히면 시작하지 않는다 (지금은 180일 뒤 실패를 기다린다).
2. 원하는 법이 막히면 막는 집단을 달랜다: 그 집단이 찬성하는 다른 법 바꾸기 중 손실이 작은 것 (예상 세입·복지 필요 감소가 작음) 을 먼저 한다. 바꾸기 충격 +5~+20 이 5년 동안 남으므로 그 사이에 원하는 법을 낸다.
3. 생활수준 항을 기다린다: 지주의 1년 생활수준 변화가 클 때 (풍작) 낸다.
4. 점수 = 법의 값 (지금 AI 식: 예상 세입, 복지 필요) − Σ 힘센 집단의 영향력 × 승인 손실. 힘센 집단을 성남(−10)까지 떨어뜨리는 바꾸기는 피한다 (단계 1 특성 −10% 때문).
5. 되돌리기 억제: 지금 시드 1 왕국 3 은 인두세 ↔ 토지세, 보편 보장 → 없음을 몇 해 사이에 오갔다 (igdiag 시드 1 13~19년차). 되돌리면 충격이 반대로 오므로 점수에 넣으면 덜 오간다.
6. 투표법 (단계 3): 원하는 법을 막는 집단의 영향력을 줄이는 쪽으로 투표권을 넓힌다. 투표법 자체도 8장 조건을 받는다 (귀족정 → 재산 투표는 지주 입장 +2 → 0 이라 지주가 만족해야 한다).

## 10. 저택 지분 (wt-manor, 스위치 끔, 안 합침) 과의 관계

- 영향력은 "인구 × 부 단계" 라서 저택 지분 자체를 세지 않는다. 지분은 귀족의 소득을 바꾸고 → 부 단계를 바꾸고 → 정치 힘을 바꾼다. wt-manor 에서 행정청의 하급 귀족이 임금 + 배당을 받으면 하급 귀족 부 단계가 올라 지주·소시민 힘이 는다.
- 부 정의를 "저축 + 지분 가치" 로 바꾸는 안 (5.1 후보) 을 고르면 저택 지분이 금융가와 같은 `Pop.fund` 에 들어가므로 (`MANOR_SHARES.md` 3.2) 따로 손대지 않아도 지주의 부에 들어간다.
- 지주 충성 특성 (저택 금고 몫 ×1.1) 은 저택 지분 아래에서도 같은 `KEEP_SHARE.manor` 에 붙는다.
- 가문 (`MANOR_SHARES.md` 4장 안, 단계 3): 빅토리아3 이익집단에는 지도자가 있고 지도자 인기 +100 ~ −100 이 끌림을 +25% ~ −25% 바꾼다 (Interest_groups, 확인함). 가문을 지주 집단의 지도자 후보로 두면: 가장 부유한 가문이 지도자, 그 가문의 지분 수익 변화가 인기 → 지주 끌림 배율. 정부 구성은 만들지 않는다 (SD6).

## 13. 남은 결정 (DECISIONS 7-45)

1. **법 저항 해석 (8장)**: (A) 반대하는 힘센 집단이 모두 만족해야 0% 가 아님 (제안) / (B) 빅토리아3 식 확률. (A) 라면 시작·끝 두 번 보는지, 복지법에도 붙이는지. 단계 0 에서 AI 법 바꾸기의 약 70% 가 막혔을 것이다.
2. **부의 정의 (5.1)**: 인구 × 부 단계 (제안) / 저축 + 지분 가치.
3. **투표법 (5.2)**: 세 단계와 0/1 가중치, 기본 귀족정 (하급 귀족·자본가 투표). 상급 귀족 ×1.5 를 둘지.

5. **지식인 집단**: 영향력 0~11%. 둘지.
6. **생활수준 항 (6장)**: 넣을지, 배율 25 (근거 없음).
7. **근거 없는 입장 (4장)**: 투자법 입장 전부, 농민 복지 입장.
8. **특성 대응 (7장)**: 대응물이 없는 다섯 칸 (지주 만족, 소시민 불만, 농민 불만·충성, 지식인 불만).
