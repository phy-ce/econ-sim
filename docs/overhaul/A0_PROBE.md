### 1.2 정의

칸 (직종 c, 왕국 k), 하루마다. `ΔS` = 틱 끝 `w.pops` 저축 합 − 틱 시작 저축 합 (지워진 pop 은 끝 값 0).
- 받은 = `recordPopIncome` 의 wages+sales+rent+dividends+welfare+other. 낸 = tax + 소비 지출(market.ts:810).
- **기타A** = ΔS − (받은 − 낸) : 지금 있는 기록만으로 잰 것.
- **기타B** = 기타A − 이동 (pops.ts:143 직종 이동·왕국 이동, :171 상속, :176 사망→w.fund).
- **기타C** = 기타B − skim(market.ts:838) − units(market.ts:849) : 3.6 이 계획한 선(받은 7종, 세금, 소비, 저택·금융가 금고로 간 몫) + 이동 선.
- 비율 = |기타| ÷ (Σ|받은| + Σ|낸| + |skim| + |units| + |저축|) (4.4 식).

### 1.8 판정과 추천

- 4.4 ε (후보 1e-9 / 1e-10 / 1e-12): 기타C 하루 최대 비율 1.1e-15 (21칸 × 1080일) → **세 후보 모두 통과**, 1e-12 에도 약 900배 여유. 기타A(지금 기록만)는 하루 최대 1.0, 해 합으로 받은 돈의 0.3%~230% → **통과 못 함**.
- 닫힘에 필요한 선: 3.6 이 이미 계획한 선(받은 7종, 세금, 소비 지출, 저택 금고 skim, 금융가 지분 매입) + 이동 선 3개 (pops.ts:143 직종 이동/왕국 이동을 나눠서, pops.ts:171 상속, pops.ts:176 사망→w.fund). 새로 찾은 '알 수 없는 이동'은 없었다. 새 pop 은 저축 0 으로 생긴다.
- **추천: 01 P3 의 약속 범위를 "장부 닫힘 전체"로 한다.** 단, 이 조건(9b46c2d, 시드 7, 3년)에서 본 것이다. 이 실행에서 돌지 않은 길: 복지(welfare.ts:118, 기록은 있음), capitalist 칸, 상속(금액 0), 옛 저장 변환(compat.ts:108), 플레이어 명령 취소(commands.ts:204). T8 은 이 길까지 덮도록 20년 시험(해마다)과 시드 2개 이상에서 다시 확인하고 ε = 1e-12 (화폐 시험과 같은 100배 이상 여유)로 시작하는 것을 제안한다.
- 표시 쪽 주의: units(지분 매입)는 돈이 지분 자산으로 바뀌는 것이라 '낸 돈'과 성격이 다르다. skim 은 위 1.4 관찰대로 이동 줄과 같이 보여야 오해가 없다. 04 문서가 정한다.
