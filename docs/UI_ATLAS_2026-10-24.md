# 평면 지도와 생성 아이콘 적용 (2026-10-24)

## 이번 사용자 지시
지도를 풍경화처럼 그리지 않고 단순한 세계 지도·역사 지도책 형태로 만든다. 문서 2-43의 건물·수목·지형 삽화 프롬프트보다 이 지시를 우선한다. 아이콘은 사용자가 첨부한 굵은 윤곽·선명한 색의 게임 소품 양식을 따른다.

## 적용
- 생성한 해안 바탕 + 공유 SVG 경계 + 실제 왕국 색으로 표시. 기존 Voronoi 분할 제거.
- 일곱 지역과 이웃 아홉 쌍을 검사. 호수·중립 구역으로 비이웃 분리. 가장자리 땅은 화면 밖으로 연속시켜 사각형 섬처럼 보이지 않게 함.
- 지도 이동·100~300% 확대·왕국/부/생활수준 레이어·지역 클릭 연결·키보드 선택 유지. 이름표는 확대해도 화면 크기 고정.
- 상품·건물·계층·지역·기상·사건 72개 아이콘 실제 연결. 술·양조장·무역소 포함. 자르는 단위는 패딩을 포함한 480px 셀 전체.
- 원본 6칸 시트 13장 → 최종 12칸 시트 7장. 최종 그림 최대 384px, 사방 패딩 최소 48px. 경계에 걸친 기존 원본 다섯 장과 배열이 잘못된 상품 시트는 재생성.
- 원본·목록·패킹 코드·검사 코드·출처와 프롬프트는 저장소에 보관. 빌드에서 지도 이웃과 아이콘 목록 누락/중복을 검사.

## 범위
2-43/2-52의 에셋 교체를 진행한 것이다. UI_CHANGES의 재정·정책·인구 등 다른 미완료 기능을 완료로 간주하지 않는다. 기존 자산은 복구를 위해 남겨 두고 런타임 참조만 새 자산으로 바꾼다.
